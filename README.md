# Обучающий проект C++

Репозиторий с практическими заданиями по языку программирования C++.

## Структура проекта

Каждый пункт учебного плана находится в отдельной директории:
* task-01/ — первое задание
* task-02/ — второе задание
* ...
* task-0N/ — N-е задание

В корне проекта настроен файл .gitignore, исключающий из системы контроля версий служебные файлы сборщиков, объектные файлы (*.o), исполняемые бинарники и настройки IDE (например, папки build/, cmake-build-debug/, *.exe, *.out).

## Сборка и запуск

Для компиляции используется скрипт build_run.sh.

## Правила выполнения

* Код должен быть написан на современном стандарте языка (C++17). Использование более новых стандартов согласуйте с преподавателем.
* Каждая задача должна находиться строго в своей папке task-*.
* Перед коммитом убедитесь, что код собирается без предупреждений компилятора (-Wall -Wextra -pedantic).
* Каждое решение должно сопровождаться кратким комментарием о логике работы программы.
